# ISO 15189:2022 Mapping

HELIOS can emit **engineering evidence** that a lab QMS may attach to an ISO 15189 assessment. It does **not** demonstrate clause compliance by itself, and a green score is not an accreditation decision.

## What the code actually does

| ISO clause (orientation) | HELIOS control | What is actually proven |
|---|---|---|
| 5.3 Examination processes | `GA4GH-REF-001` | BAM/CRAM `@SQ` UR/M5 matched known GRCh38 contig MD5s. No artifact → **fail**. |
| 5.6 / 8.6 | `SEC-CONTAINER-001` | Workflow + trace container refs are digest-pinned. Zero refs → **fail**. |
| 7.3.2 Reporting | `CLIN-VUS-001`, `GA4GH-MANE-001` | VUS % and MANE usage when annotations exist. No data → **skip**, not pass. |
| 7.7 Nonconforming work | Aggregate score | Fail/warn/pass counts. Skip-only suites grade **N/A**, never 100. |

`AuditRecord` is a frozen Pydantic model. Persistence is SQLite (mutable file). Integrity comes from Ed25519 signatures verified against the operator **trust store**, not from the database.
